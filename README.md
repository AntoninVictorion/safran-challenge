# Safran Challenge – préparation

Détection de panne sur séries temporelles (NASA C-MAPSS, sous-jeu FD002).

## Données
Télécharger `6. Turbofan Engine Degradation Simulation Data Set.zip` depuis le NASA Prognostics Data Repository
et extraire les fichiers `.txt` dans `data/` (non versionné).

## Contenu
- `script.ipynb` : exploration (régimes, sélection des capteurs, normalisation par régime)
